# Loom video script (~2:30)

Record the screen at 1440px wide. Open `prototype/index.html` in Chrome, plus the GitHub repo in a second tab.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Your face / repo README | "Hi, I'm Aliyan. Most people will send you a cover letter. I spent the time building a discovery MVP of your EDMS instead, so you can judge how I think before you hire anyone." |
| 0:15 | Dashboard | "This is the dashboard: my approval tasks, recent documents, and compliance status, like the audit chain check and records due for disposition." |
| 0:30 | Repository → Legal / Contracts | "Standardized folder structures come from templates, so departments can't drift. This folder is restricted and has a strict upload policy." |
| 0:45 | Upload → drop files | "Bulk upload. The policy forces required metadata **before** anything is saved. Watch: a wrong reference number is flagged, and a TIFF isn't allowed here, but it can be converted to searchable PDF/A. Save stays disabled until everything passes." |
| 1:05 | Open MSA → Versions → Compare | "Every document has immutable versions. Here's a compare of v2 against v3: payment terms and indemnity cap changed. Restore creates a new version and never overwrites history." |
| 1:20 | Workflow tab → Approve | "Linear approval: Legal, then Finance, then MD. The approval is bound to that exact version and confirmed with MFA." |
| 1:35 | Activity / Audit log | "Every view, download, edit and approval is logged with user, time and IP, and the log is hash-chained so it can't be quietly edited." |
| 1:45 | Search "indemnity" | "Full-text search across Word files **and scanned paper**: this hit comes from OCR text. Filters cover type, department, dates and folder." |
| 1:55 | Switch role to Viewer | "Access control: I switch to a Viewer. Admin menus disappear, the HR folder disappears, and restricted documents are removed from search results entirely." |
| 2:05 | Records → Legal holds → Disposition | "Records management: retention rules, legal holds that block deletion at the storage level, and defensible deletion with two-person approval and a destruction certificate." |
| 2:15 | Repo docs folder | "The repo also has the full proposal: scope, architecture, stack, security, testing, a 16-week milestone plan with fixed pricing, and assumptions." |
| 2:25 | Face | "I'd suggest a short call to go through it together. Thanks for watching." |

**Tips:** Click before you speak about each element. Keep the mouse still while talking. Do one take per section and cut them together.
